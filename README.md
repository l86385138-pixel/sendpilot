# SendPilot

SendPilot is a clean campaign-management web app built with Firebase and GitHub Pages.

## Current phase
- Landing page
- Firebase Email/Password authentication UI
- Firestore user profile creation
- Responsive dashboard-ready structure

## Firebase
Add the Web App configuration in `app.js` before testing authentication.

## Important
WhatsApp messaging should use the official WhatsApp Business Platform/Cloud API and permission-based recipients. Do not automate WhatsApp Web or unsolicited messaging.
